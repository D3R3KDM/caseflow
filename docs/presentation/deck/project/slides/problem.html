Part one is the problem. Each of the eight mounts can be empty, blow in, or blow out. That is three to the eighth: 6,561 layouts. One simulation of one layout takes 90 seconds on my RTX 5080, so all of them would take about a week, and that is for one room temperature, one load and one set of fan curves. So the question is: can AI make this search fast enough to be interactive?
