So how does it work? That is part three. There are three pieces. The engine, in Python and PyTorch, runs on my GPU and simulates a layout once; the result is cached. A small FastAPI service runs simulations as jobs and serves the network. And a React and three.js web app does the rest, including solving the temperatures.
